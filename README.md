**Niche Block**

Niche Block was started on December 16th, 2025, intended to function as a gaming platform.
You can paste this code onto any website and it will give you a fully developed games page
with over 100 games!

View instructions below to view how to use it.

1 - Copy either the 'html' or 'shortened-html' file.
2 - Paste the code into an HTML previewer or in an embed on Google Sites
3 - Have fun

Access the Niche Block main page at sites.google.com/view/niche-block-5
